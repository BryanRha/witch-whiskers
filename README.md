# 냥냥 마녀 (Witch & Whiskers)

빗자루를 탄 마녀가 고양이 친구들과 밤하늘을 날며 몬스터 줄을 뚫고 나아가는 세로 스크롤 슈팅 게임 (H5, Phaser 3).
드래곤플라이트의 구조(5칸 줄 · 거리 기록 · 별똥별 · 보스 · 아이템 · 펫)를 참고했고, 그림·소리·이름·수치·코드는 모두 새로 만들었습니다.

- 조작: 화면 아무 곳이나 누른 채 좌우로 밀기 (PC는 ← → 키도 됨)
- 마녀 4명(루나·피아·시엘·볼트) · 고양이 12마리(공격·지원·탐험) · 보스 3종 · 구역 5곳
- 확률형 뽑기 없음: 비행 중 모은 발바닥 도장으로 정해 둔 고양이를 입양
- 미션 · 출석 · 업적 · 주간 랭킹(게임 속 마녀들) · 산책(탐험) · 상점(게임 재화 교환)

## 개발
```
node tools/sync.js --mirror      # ../assets → assets/ + ~/witch-dist (개발 서버 폴더)
node tools/bot.js 40 1 0.5       # 밸런스 봇 (판 수, 마녀 레벨, 실력)
node tools/e2e.mjs http://localhost:3300 ./shots 2 3   # 브라우저 통합 테스트
bash tools/deploy_pages.sh "변경 내용"                  # GitHub Pages 배포
```
테스트 주소 옵션: `?play`(로비로 바로) · `?bot`(자동 비행) · `?from=1400`(그 거리부터 시작)
